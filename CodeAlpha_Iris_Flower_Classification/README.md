# Iris Flower Classification

This project is part of my CodeAlpha Data Science Internship.

## Objective
Build a Machine Learning model to classify Iris flowers into Setosa, Versicolor, and Virginica species using Scikit-learn.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Files Included
- Iris_Flower_Classification.ipynb
- iris.csv
- Graphs and Visualizations
